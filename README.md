# @jankrajewskiit/data

Heavy data-visualization and grid components extracted from `@jankrajewskiit/ui`.

## Contents

- `TradingViewChart` (+ `useTradingViewWsFeed`, `useTradingViewPollingFeed`)
- `DataGridPro`
- `ColumnManager`
- `QueryBuilder`
- `TableAddRowAction`

## Peer dependencies

- `@jankrajewskiit/ui` — primitives (Button, Card, Input, Text, ...)
- `solid-js`, `solid-icons`
- `lightweight-charts` (optional, required for `TradingViewChart`)
